# rdkit is a range, deliberately, as in the Kinase Foundation Model. It never
# touches the forest; it computes the compound block, and releases 2024.03.6
# through 2025.09.5 compute byte-identical features over 3,285 structures.
# Earlier 2024.03 releases predate numpy 2 support. One exact pin breaks
# installation on Intel macOS, where rdkit's last wheel is 2025.9.3, including an
# Intel Python running under Rosetta on Apple Silicon. Check with:
#   python -c "import platform; print(platform.machine())"
# The cap is for reproducibility. From 2025.09.6 RDKit no longer counts a fully
# deuterated methyl as a rotatable bond, which is the more correct convention;
# the models were built on the earlier one, so later releases change the features
# of isotope-labeled compounds. The reference replay does not see that change,
# and familyfm.rdkit_check, which install.sh runs, does. Re-run it before raising
# the cap:
#   python -m familyfm.rdkit_check
rdkit>=2024.3.6,<=2025.9.5
