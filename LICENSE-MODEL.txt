WHY SHARE-ALIKE, WHEN THE CODE IS APACHE 2.0
--------------------------------------------
This model is trained on ChEMBL 37 and on nothing else. ChEMBL is released by
the European Bioinformatics Institute under Creative Commons
Attribution-ShareAlike 3.0 Unported. A set of forest weights fitted on that data
is a derived work of it, so the weights carry ChEMBL's attribution and
share-alike conditions forward rather than dropping them. CC BY-SA 4.0 is the
current version of the same license and is one-way compatible with 3.0.

The training and inference CODE in this repository is separate and is Apache
2.0. Using the code with your own data puts no obligation on you from this file.

WHAT THIS MEANS IN PRACTICE
---------------------------
You may use the weights commercially, redistribute them, and build on them.
If you distribute the weights or a model derived from them, you must:

  * credit ChEMBL and this project, and
  * release your derived weights under CC BY-SA 4.0 or a compatible license.
